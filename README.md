# Observability Stack

Local platform based on Prometheus, Grafana, Alertmanager, Loki, Promtail and node_exporter.

```bash
docker compose config
docker compose up -d
docker compose ps
```

- Grafana: http://localhost:3000
- Prometheus: http://localhost:9090
- Alertmanager: http://localhost:9093

Default credentials are intended only for a local lab.
